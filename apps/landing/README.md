# Perfume Ecommerce Landing Page

Live Demo: [Explore the Landing Page](https://senz8-landing.vercel.app)

A modern, animated landing page for the Senz8 perfume ecommerce platform, built with **Next.js**, **Three.js**, and cutting-edge animation libraries to create an immersive, interactive experience.

---

## Project Overview

This landing page is designed to introduce the brand, showcase products, and engage users with **dynamic 3D visuals and smooth animations**. It serves as the first touchpoint for customers and is optimized for **performance, interactivity, and modern web standards**.

---

## Key Features & Contributions

- **3D Graphics & Animation**  
  Used **Three.js** with `@react-three/fiber` and `@react-three/drei` to create interactive, visually appealing 3D scenes that enhance the brand experience.

- **Smooth Animations**  
  Implemented **GSAP** and **Framer Motion** for seamless entrance effects, transitions, and scroll-based animations, creating a polished and modern user experience.

- **Next.js Frontend**  
  Built with **Next.js** for performance, server-side rendering, and maintainability.

- **Interactive & Immersive UI**  
  Designed the landing page to be **responsive, interactive, and visually engaging**, ensuring users are immediately drawn into the brand story.

- **Modern Frontend Practices**  
  Structured the codebase with **React functional components**, reusable hooks, and optimized 3D assets for fast load times.

---

## Technology Stack

- **Frontend & Framework:** Next.js
- **3D Graphics:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations:** GSAP, Framer Motion
- **State & Interactivity:** React hooks and Zustand
- **Styling:** Tailwind CSS / custom CSS
